
# AI Detective – Test Cases

| Test | Scenario | Expected Result |
|---|---|---|
| 1 | Generate a new mystery | AI generates a story with 3 suspects and 3 clues |
| 2 | Select the correct culprit | Application displays success message |
| 3 | Select the wrong culprit | Application displays an incorrect answer message and reduces score |
| 4 | Request an AI hint | Gemini provides a hint without revealing the culprit |
| 5 | API key is missing or invalid | Application displays an understandable error message |

## Testing Summary

The test cases cover mystery generation, suspect selection, scoring, AI hints and API configuration.

The tests describe expected behaviour and should be executed to confirm the results.
