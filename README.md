# AI Detective – The Mystery Solver

## Project Overview
AI Detective is an AI-powered detective escape room application developed using Python, Streamlit and Google Gemini API.

The application generates detective mysteries where players investigate clues, analyse suspects and identify the criminal to escape.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Generative AI
- Google Colab

## Features
- AI-generated detective mysteries
- Three suspects and three clues
- Easy, Medium and Hard difficulty levels
- AI-powered hints
- Interactive criminal selection
- Score tracking
- Case-solving explanations

## Version 1
The initial version of the application introduced the basic detective mystery experience.

## Version 2
The improved version integrates Google Gemini AI to generate dynamic mysteries and provide hints.

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## API Configuration

Set your Gemini API key as an environment variable:

```bash
GEMINI_API_KEY=your_api_key_here
```

Never upload your actual API key to GitHub.

## Run the Application

```bash
streamlit run app.py
```

## Project Objective
To demonstrate practical knowledge of Python, Generative AI, LLM integration and interactive application development.
